# Drop

局域网文件速传。手机扫码连上同一 Wi-Fi 下的电脑，拖拽即传，文件落在电脑的接收目录。

Toolbelt 的第一个第一方工具（first-party tool），零 npm 依赖。

## 用法

在 Toolbelt 里安装本仓库，启动后在工具架打开页面：

- 页面显示局域网地址二维码，手机扫码即连（PIN 已带在链接里）。
- 手机端输入 PIN 也可手动连接；PIN 显示在电脑页面上。
- 拖文件到页面即上传到电脑的接收目录；电脑上的文件出现在列表里供手机下载。

## 功能

- **文件互传**：拖拽/多选上传到接收目录；列表可下载、删除、一键打包 zip。
- **文本速传**：手机贴一段链接或文字直接发到电脑，落成 txt。
- **快速预览**：图片缩略图/大图预览，文本前 64KB 直接看，不用先下载。
- **选中打包**：勾选若干文件打包 zip，或全部打包下载。
- **扫码配对**：局域网地址二维码（自动过滤 VPN/隧道网卡），PIN 门禁（本机免验）。

## 设计决策

- **零 npm 依赖**：`node:http` 原生实现，multipart 解析自研（流式、边界串行队列），二维码用纯前端 SVG 生成（ISO/IEC 18004 字节模式）。安装即用、无供应链风险。
- **安全模型**：写操作（上传/删除）需要 6 位 PIN；**回环地址（本机）免验**——本机是所有者，手机等局域网设备需要 PIN。首次启动随机生成 PIN 并持久化到 `uploads/.drop-config.json`，重启不变。手机扫码链接自带 PIN。
- **文件落盘位置**：默认 `~/Downloads/Drop`（用户在访达里顺手能找到），可用环境变量 `DROP_UPLOAD_DIR` 覆盖。Toolbelt 托管时通过 daemon 环境变量传递。
- **端口**：读环境变量 `PORT`（Toolbelt daemon 动态分配），独立运行时默认 4210。监听 `0.0.0.0` 保证手机可达；回环免验因此不影响本机安全。
- **上传协议**：`POST /api/upload` multipart/form-data；服务端流式写盘不驻内存（50MB 文件实测 43ms）；同名并发上传按浏览器/服务器时序覆盖（个人工具可接受）。
- **接收目录内 `.drop-config.json` 是配置文件**，列表接口已过滤点开头的文件。

## 边界（v1 未做）

- 不做文件夹上传、不做断点续传、不做远端加密（限定局域网使用）。
- 「在访达中打开」仅在 macOS 生效（`open` 命令）。
